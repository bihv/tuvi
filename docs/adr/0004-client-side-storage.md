# Lưu trữ Lá số và Lịch sử hoàn toàn ở Phía Trình duyệt (Client-side Persistence)

Hệ thống cần cung cấp trải nghiệm tức thì cho người dùng phổ thông mà không tạo rào cản đăng nhập/đăng ký tài khoản hay chi phí duy trì cơ sở dữ liệu máy chủ. Chúng tôi quyết định sử dụng **Pinia (`@pinia/nuxt`)** kết hợp plugin **`@pinia-plugin-persistedstate/nuxt`** để quản lý và tự động đồng bộ danh sách lá số cùng lịch sử trò chuyện xuống LocalStorage của trình duyệt (`persist: true`). Đối với quản lý server state, fetching và caching dữ liệu không đồng bộ, chúng tôi sử dụng **TanStack Query (`@tanstack/vue-query` qua module `@hebilicious/vue-query-nuxt`)** kết hợp với **`$fetch`** của Nuxt để gọi các Nitro Server Routes. Quyết định này giúp tối ưu trải nghiệm người dùng, tận dụng cơ chế caching/refetching chuẩn công nghiệp của TanStack Query và loại bỏ hoàn toàn code thao tác thủ công.
